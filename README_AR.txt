تحدي الملوك — مشروع أندرويد تجريبي

هذا مشروع Android Studio مبني على نسخة HTML رقم 26 دون تغيير محتواها.

لإنتاج APK:
1. افتح مجلد المشروع في Android Studio على جهاز كمبيوتر.
2. اسمح بتنزيل Android SDK وGradle والمزامنة.
3. اختر Build > Build APK(s).
4. ستحصل على APK تجريبي في app/build/outputs/apk/debug/.

تنبيهات:
- الملف المرفق مشروع مصدر، وليس APK جاهزًا للتثبيت.
- لم يُختبر على هاتف أندرويد ولم يُبنَ APK في هذه البيئة.
- قبل نشر Google Play: اختبر الأصوات وWebView، وأضف أيقونة أصلية وسياسة خصوصية، ووقّع إصدار AAB، وراجع متطلبات المتجر.
- لا توجد إعلانات أو SDK إعلاني مدمج في هذه النسخة.
- تخزين النقاط محليًا وقد يُحذف عند حذف التطبيق.
